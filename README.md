## 🚀 Projects

### 1. NexusRAG — Hybrid Retrieval-Augmented Generation

An experimental RAG system designed to improve document-based question answering through hybrid information retrieval.

**Technologies:**
- Python
- PyMuPDF
- FAISS
- BM25
- Multilingual E5 Embeddings
- Reciprocal Rank Fusion (RRF)
- BGE Reranker
- Qwen2.5-1.5B-Instruct

**Key Features:**
- PDF document extraction
- Text chunking and embedding generation
- Dense and sparse retrieval
- Hybrid search with Reciprocal Rank Fusion
- Cross-encoder reranking
- LLM-based answer generation

**Status:** Core retrieval and generation pipeline implemented.

### 2. MediGuide AI — Medical LLM Fine-Tuning

An educational medical language model project exploring parameter-efficient fine-tuning using QLoRA.

**Base Model:** Qwen3-4B

**Datasets:**
- MedQA
- PubMedQA

**Technologies:**
- Python
- PyTorch
- Hugging Face Transformers
- Hugging Face Datasets
- PEFT
- LoRA / QLoRA
- BitsAndBytes
- Kaggle GPU

**Planned Features:**
- Medical dataset preprocessing
- 4-bit model quantization
- QLoRA fine-tuning
- Model evaluation
- Inference testing

**Status:** Dataset preparation and model loading completed. Fine-tuning and evaluation are pending.

**Disclaimer:** This is an educational and research project, not a clinical decision-support system. It is not intended to diagnose conditions or recommend treatments.
